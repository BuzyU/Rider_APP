### 2.3 Foreground Service Safety on Android 8+ and API 34+ (Fixes N10, M4)
- In `MeshForegroundService.onStartCommand()`, `ensureStartedForeground(notification)` is invoked immediately upon entry before any early returns (`ACTION_STOP_SERVICE`, gate disabled, or transport not connected). This eliminates `ForegroundServiceDidNotStartInTimeException` crash window on Android 8+ (M4).
- On Android 14+ (API 34+), microphone permission `RECORD_AUDIO` is checked via `ContextCompat.checkSelfPermission` before declaring `FOREGROUND_SERVICE_TYPE_MICROPHONE`. If permission is absent, service starts as standard foreground without crashing.

### 2.4 Application-Scoped Teardown Dispatch (Fixes N8)
- In `OfflineMeshViewModel`:
  - `stopSession()` launches onto `appScope: CoroutineScope` (SupervisorJob + Dispatchers.IO).
  - In `onCleared()`, `stopSession()` dispatches `transport.stop()` (which transmits the `BYE` frame and releases network locks/audio hardware) onto `appScope`.
  - Because `appScope` is not cancelled when `viewModelScope` is cancelled, the `BYE` frame is guaranteed to be transmitted over the socket before VM GC.
