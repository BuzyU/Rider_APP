## 2. Production Call Chains

### 2.1 Single AudioRecord & Effects Lifecycle (Fixes N11, V1)
- In `OfflineAudioCapture.kt`:
  - Enforces single `AudioRecord` lifecycle; only instantiated when `gateAllowed() && micEnabled && canClaimAudio() && hasMicPermission()`.
  - Specific exception handling: catches `IOException`, `IllegalStateException`, `SecurityException`, rethrows `CancellationException`, surfaces errors via `onCaptureError` into diagnostics.
  - On `stop()` and `releaseInternal()`, explicitly releases and nulls hardware effects: `AcousticEchoCanceler` (`aec?.release()`), `NoiseSuppressor` (`ns?.release()`), and `AutomaticGainControl` (`agc?.release()`).

### 2.2 LiveKit Quiet Guard Window & Sealed Return Type (Fixes V15, V16)
- In `MeshControl.kt`:
  - `enableAudio()` returns `sealed interface EnableAudioResult` (`Success | Failure(reason)` with subclasses `OwnershipDenied`, `HardwareBusy`, `GateClosed`).
- In `VoiceSessionCoordinator.kt`:
  - `fallbackToMesh()`:
    1. Pauses LiveKit (`liveKitTransport.pause()`).
    2. Enforces `verifyLiveKitQuiet(timeoutMs = 2_000L)` requiring LiveKit muted and VOX stopped for >= 400 ms.
    3. Aborts and rolls back to `LIVEKIT` owner if LiveKit does not become quiet.
    4. Only commits `OFFLINE_MESH` owner after `mesh.enableAudio()` returns `EnableAudioResult.Success`.
    5. On any failure, restores ownership to `AudioOwner.LIVEKIT` and resumes LiveKit.

### 2.3 Mic Semantics & Truth Table (Fixes N5, Q7)
- In `MeshVoxBridge.kt`:
  - Evaluates Q7 mic semantics: `audioEnabled && (micToggleOn || pttHeld || (voxEnabled && armed))`.
  - PTT release never closes a toggle-opened mic.
  - Helmet PTT key acts as a toggle flip (`isMicToggledOn = !isMicToggledOn`).
  - Saves and restores previous `HardwarePttPort` callback on `close()`.
  - Defaults to `Dispatchers.Default` and uses `scope.coroutineContext.cancelChildren()` on `close()` so the bridge remains operational across multiple sessions.

### 2.4 Playback & Jitter Buffer Robustness (Fixes N11)
- In `OfflineAudioPlayback.kt`:
  - Playout thread priority set to `android.os.Process.THREAD_PRIORITY_URGENT_AUDIO`.
  - Injects silence frames on underruns and tracks underrun counts.
  - Immediately stops and releases `AudioTrack` on pause/stop without silent `catch (Throwable)`.
- In `JitterBuffer.kt`:
  - Clarified fixed 3-frame target delay (60 ms).
  - Handles 32-bit sequence wrap-around correctly with modular distance calculation.

### 2.5 Audio Route Controller Invariant (Fixes N6)
- In `MeshAudioRouteController.kt`:
  - Checks `arbiter.owner.value == AudioOwner.OFFLINE_MESH` prior to acquiring communication mode or changing routing.
  - Remains completely inert when `AudioOwner.LIVEKIT` or `AudioOwner.NONE` owns audio.
