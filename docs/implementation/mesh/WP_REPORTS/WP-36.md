- **A5 (HIGH)**: `OfflineMeshVoiceTransport.kt`, `MicRules.kt` — AudioRecord capture runs whenever `audioEnabled && (micToggleOn || pttHeld || voxEnabled)`, allowing warm capture for hands-free speech detection.
- **A6 (HIGH)**: `MeshVoxBridge.kt` — Removed listener registration in `init`; added `attach`/`detach` lifecycle with reference identity check (`port.onMicToggleRequest === ownCallback`) to avoid clobbering third-party handlers.

- **A9 (HIGH - early resolution)**: `VoiceSessionCoordinator.kt:175` — Deleted the `liveKitTransport.stop()` call on mesh enableAudio failure so LiveKit remains paused and is never disconnected from the mesh side.
- **A25 (HIGH - early resolution)**: `AutomaticSwitchStateMachine.kt` — Confined `!offlineAvailable` early return to entry states (`ONLINE`, `ONLINE_SUSPECT`, `FALLBACK_UNAVAILABLE`), allowing active `OFFLINE_ACTIVE` sessions to recover to LiveKit even if offline session expires.
- **A27 (HIGH - early resolution)**: `AutomaticSwitchStateMachine.kt` — Implemented ticketed non-blocking handoff per CODE-2 so `endSession()` completes promptly without blocking behind `mutex.withLock`.
- **A28 (HIGH)**: `LiveKitVoiceTransport.kt` — `restartVoxIfPreviouslyRunning()` only executes when `connectionState == CONNECTED`.
- **A39 (HIGH)**: `OfflineAudioCapture.kt` — Added `MAX_EMPTY_READS = 50` to avoid infinite spin-looping on consecutive 0-byte reads from uninitialized or dead `AudioRecord`.
- **A40 (HIGH)**: `OfflineMeshVoiceTransport.kt` — `failEnable()` cleanly rolls back `audioCapture`, `audioPlayback`, communication mode, locks, and arbiter ownership on partial failure.
- **A41 (MEDIUM)**: `OfflineMeshVoiceTransport.kt` — `startDiscoveryOnly()` properly terminates previous active session when called with a new session ID and updates projected peers synchronously; `stop()` clears `micWanted` and `paused`.
- **A42 (HIGH)**: `OfflineAudioCapture.kt` — Preserves `offset` on `read == 0` with 10 ms delay instead of breaking and discarding partial frames.
- **A46 (LOW)**: `OfflineMeshVoiceTransport.kt`, `OfflineRoomScreen.kt` — Transport exposes `StateFlow<Boolean> deafened`; HUD UI observes it; default `voxEnabled` is `false`.
- **A47 (LOW)**: `MicController.kt` — Conflated channel `Channel<Boolean>(Channel.CONFLATED)` collapses rapid bursts and strictly preserves order.
