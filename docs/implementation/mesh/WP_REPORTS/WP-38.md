## 1. Summary of Changes
- **A8 (Non-disruptive recovery)**:
  - Added pauseCaptureOnly() and 
esumeCaptureOnly() to MeshControl interface and implemented in OfflineMeshVoiceTransport.
  - Re-implemented 
ecoverToLiveKit() in VoiceSessionCoordinator per CODE-6: when online recovery begins, offline AudioRecord is paused via mesh.pauseCaptureOnly(), but mesh playback stays active (no dead air) while waiting up to 15s (RECOVERY_CONNECT_TIMEOUT_MS) for LiveKit VoiceTransportState.CONNECTED.
  - If LiveKit fails to connect within 15 seconds, rollback calls mesh.resumeCaptureOnly() without having ever stopped mesh playback.
  - Mesh playback is stopped (mesh.disableAudio()) only after LiveKit successfully connects and claims audio ownership.

    - 
ecovery_keepsMeshAudioUntilLiveKitConfirmed: Mesh playback stays enabled and capture paused while LiveKit reconnects.
    - 
ecovery_noDeadAir: Mesh playback stays active across the 15s reconnect window.

ecovery_timeout_keepsMeshCapture: Timeout rolls back to mesh capture without stopping playback.
