## 1. Summary of Changes
1. **Network Ports & Single Mesh Port:**
   - Consolidated `AUDIO_PORT` and `DISCOVERY_PORT` to `MESH_PORT = 45454` in `MeshConfig.kt`.
   - Updated simulation and acceptance test fixtures to use `MeshConfig.MESH_PORT`.
2. **TTL & Hop Count Hardening:**
   - Enforced maximum hop limit `MAX_HOPS = 7` in `MeshConfig.kt` and `TtlPolicy.kt`.
   - Unified TTL policy: packets dropped when `ttl <= 0`, `hopCount > MAX_HOPS`, or `ttl + hopCount > DEFAULT_TTL`.
   - Passed `decoded.hopCount` from `ForwardingEngine.kt` to `TtlPolicy.isTtlValidOnReceive`.
3. **UDP Mesh Link Hardening:**
   - Added `CoroutineExceptionHandler` to catch unhandled coroutine exceptions.
   - Implemented exponential backoff in receive loop from 100ms up to 2,000ms.
   - Implemented `endpoints(): Set<MeshEndpoint>` returning unexpired active peers within `expiryWindowMs`.
   - Preserved D22 invariant: unauthenticated frames do not register endpoints.
4. **Thread-Safe Routing Table:**
   - Synchronized `RoutingTable.recompute` and implemented atomic immutable snapshot swapping.
   - Updated docstrings to clarify Breadth-First Search (BFS) routing over link-state topology, not distance-vector.
5. **Reactive Peer Projection & Background Expiration:**
   - Replaced 500ms polling loop in `OfflineMeshVoiceTransport` with reactive `StateFlow` collection of `graphRepository.snapshots`.
   - Added 500ms scheduled sweep for `graphRepository.expire()` and periodic diagnostics refresh.
   - Acquired low-latency Wi-Fi lock strictly during `enableAudio()`, releasing on `disableAudio()`, `pause()`, and `stop()`.
6. **Codec Resilience:**
   - Enforced `MAX_PAYLOAD_BYTES` and oversized buffer limits in `MeshPacketCodec.decode`.
   - Wrapped decode in safe exception handling returning `DecodeResult.Invalid` rather than throwing on malformed datagrams.
7. **Runtime Settings Reactivity:**
   - Added `settingsFlow: StateFlow<MeshSettingsSnapshot>` backed by `SharedPreferences.OnSharedPreferenceChangeListener`.
   - Connected `MeshAutoSwitchManager` to re-evaluate dynamically on gate and preference changes.
8. **Debug Peer Filter Safety:**
   - Guarded `MeshConfig.debugPeerFilter` behind `isDebugBuild = BuildConfig.DEBUG`, making it a no-op in release builds.
